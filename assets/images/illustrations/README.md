# assets/images/illustrations

Reserved for additional custom illustrations beyond the page-scoped ones
already in use (the hero network graphic, service icons, and technology
stack visual currently live under their respective page folders —
`home/`, `services/`, `technology/` — rather than here, since each is
tied to a specific page).

Use this folder for illustrations that are shared across multiple pages
or don't belong to a single page's content (e.g. a reusable "under
construction" graphic, a shared error-state illustration, etc.).
