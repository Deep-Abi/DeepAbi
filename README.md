# DeepAbi Innovations

Marketing and service website for **DeepAbi Innovations**, a software
development company based in Mogappair, Chennai. Static HTML, CSS and
JavaScript generated by a small set of Python scripts — no framework, no
bundler, no runtime dependencies.

## Layout

```
/                    generated pages (*.html), sitemap.xml, robots.txt
assets/images/       source images, grouped by page then format
css/                 common.css + css/pages/<page>.css
js/                  common.js + js/pages/<page>.js
scripts/             build_site.py (shared template) + scripts/pages/build_*.py
docs/                developer documentation and historical change notes
reports/             audit and verification output (not deployed)
```

## Build

```
cd scripts/pages && python3 build_home.py   # ...and the other build_*.py
```

Read **[docs/BUILD.md](docs/BUILD.md)** before editing: the root `.html` files
are generated output, and hand-edits there are overwritten by the next build.
